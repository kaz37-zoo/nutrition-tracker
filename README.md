# トレログ＋ v1.1

筋トレの記録・進捗管理を行う、個人用Webアプリです。

## 主な機能

- 種目・セット・回数・重量の記録
- 履歴の確認と編集
- 前回記録のコピー
- RIR・痛み・メモの記録
- 休憩タイマー
- JSON形式でのバックアップ／復元
- ホーム画面への追加
- 初回読み込み後のオフライン起動

## GitHub Pagesで公開する手順

1. このフォルダ内のファイルを、リポジトリの `main` ブランチ直下へアップロードします。
2. GitHubのリポジトリで `Settings` を開きます。
3. `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/ (root)` にして `Save` を押します。
6. 数分後、公開URLが表示されます。

このリポジトリ名が `-training-log` の場合、公開URLは通常次の形式です。

`https://kaz37-zoo.github.io/-training-log/`

## iPhoneでアプリのように使う

1. 公開URLをSafariで開きます。
2. 共有ボタンを押します。
3. `ホーム画面に追加` を選びます。

## データ保存について

記録はSafariの `localStorage` に端末内保存されます。

- 別端末とは自動同期されません。
- SafariのWebサイトデータを削除すると、記録が消える場合があります。
- 定期的にアプリ内のJSONエクスポートを使用してください。
